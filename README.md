# Denné úlohy

Krátka denná dávka úloh na tréning hlavy: príklady, číselné postupnosti a bludisko.
Úlohy sa generujú z dátumu, obtiažnosť sa nastavuje parametrom v odkaze.

Čisté HTML, CSS a JavaScript, bez závislostí. Testy: `node testy/spusti.mjs`.

Písmo: [Lexend](https://www.lexend.com/), licencia SIL Open Font License 1.1 (`fonts/OFL.txt`).
